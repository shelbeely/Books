# Introduction

Welcome to this zine. This document was built from Markdown source and packaged as
an EPUB optimized for the Xteink X4 e-ink display running CrossPoint firmware.

## About This Zine

The text you are reading was written in plain Markdown and converted to EPUB using
a simple Python build script. No special tools, no cloud services, no JavaScript —
just readable text on a crisp e-ink screen.

## Reading Tips

- Use your device's font-size controls to adjust text size.
- The layout is intentionally simple so it looks good at any font size.
- Images are scaled to fit the page width automatically.
